一、执行摘要

当前 DGAPred 项目的主要问题不是“模型不够复杂”，而是标签矩阵稀疏、未观测 0 被当成负样本、ADR 低支持严重、不同相似性矩阵分布不一致，以及固定 0.5 阈值不适合 MCC/ACC。已有 5 epoch 远程实验显示，fold-local 阈值校准是当前最稳的短期增益来源；D4 相似性负采样仅带来很小 AUC/AUPR 提升，暂不适合作为主贡献。

推荐下一轮主线 以 fold-local threshold calibration 作为当前主线；PU-weighted BCE 已完成初筛但低于阈值校准，不建议继续作为主贡献。下一步优先补齐 30 epoch 未校准 base 对照，再考虑 低支持感知采样 或更保守的 side-aware 风险建模。
实现状态更新 PU-weighted BCE 五折初筛已完成，均值为 AUC 0.91042、AUPR 0.90573、ACC 0.83285、MCC 0.66598，低于 5 epoch 阈值校准结果；30 epoch 阈值校准五折验证已完成，最终均值为 AUC 0.93023、AUPR 0.92643、ACC 0.85587、MCC 0.71201。远程已启动 e30_base_quiet_u 作为同配置未校准 base 对照。

四、文献依据与可借鉴模式

方向代表依据能转化为 DGAPred 的点
可靠负样本 / PU learning Zheng et al., Inverse similarity and reliable negative samples for drug side-effect prediction; DDI-PULearn 的正-未标注学习思路。 把未观测 0 视作 unlabeled，而不是同等可信负样本；用相似性和先验风险给训练负样本降权或筛选。
多视图 drug/ADR 表征 多视图 drug side-effect association prediction、multi-kernel/multi-knowledge graph 类工作。 当前已有 RDKit/DGen/GE 与 MESH/GDA，可做 view-level gating、视图归一化、视图 dropout，而不是盲目加深网络。
图与相似性传播 药物副作用预测中常见 GNN、heterogeneous graph、attention/capsule 网络。 当前模型按 pair batch 计算，没有显式利用全局 drug-ADR 二部图传播；可加入轻量 label propagation 或 PPR-style prior。
不平衡分类阈值与 MCC Boughorbel et al., Optimal classifier for imbalanced data using MCC。 已实现训练折阈值校准；可扩展为 Platt/temperature calibration 或 per-support-bin threshold。

五、候选改进方向优先级

优先级方向针对问题实现方案预期影响风险
1 PU-weighted BCE / nnPU 风格训练损失 0 标签不是可靠真负；当前 BCE 对正负同等信任。 为负样本引入可靠度权重 w_neg = 1 - risk；或按正类先验估计 PU risk。先做保守版本：只在 BCE 中对负样本加权，不改变测试集。 可能提升 AUC/AUPR，比单纯采样更连续、更稳定。 权重过低会降低区分硬负样本能力；需要 ablation。
2 side-aware 伪负风险评分 当前 D4 只用 drug 相似性，高风险估计不足。 负样本风险 = drug-neighbor positive evidence + ADR-neighbor positive evidence。利用 side_mesh_sim 和 adr_GDisease_sim 对相似 ADR 传播风险。 比现有 D4 负采样更贴合 ADR 低支持问题，可能提升 AUPR。 ADR 相似性过强可能把难负样本误判为伪负。
3 低支持感知采样 / loss reweighting ADR 单例/低支持样本多，训练中难以稳定学习。 按 drug/ADR 支持度给正样本和负样本分桶；对低支持 ADR 的正样本适度加权，对其负样本降低置信。 可能提升低支持区域召回和 AUPR；与阈值校准互补。 过度加权会牺牲高支持 ADR 的总体 ACC。
4 视图归一化 + view dropout/gating GE 相似度含负值且分布不同，特征视图质量不均。 对每个相似性矩阵做可选 min-max/z-score；训练时随机 drop 一个 drug view 或加入可学习 view gate。 提高表示稳健性，减少某一噪声视图主导。 效果依赖视图质量；实现要保持 ablation 开关。
5 轻量 label propagation / prior score 融合 当前模型 pair-wise 训练，未显式利用全局相似图传播。 离线计算 drug/ADR 相似图上的传播先验，例如相似 drug 对 ADR 的 max/mean positive score，再作为额外输入或 logit residual。 可能直接提升冷门 ADR 和稀疏区域排序。 要严格 fold-local，不能用测试正样本泄漏进训练先验。
6 温度/概率校准扩展 固定阈值已证明不是最优。 在训练 fold 上做 temperature scaling 或 Platt scaling，再选阈值。 主要提升 ACC/MCC，AUC/AUPR 通常不变。 论文贡献偏后处理，需和训练改进组合。

六、推荐实验路线

路线 A：最快验证 AUC/AUPR 提升

  1. 实现 --use_pu_negative_weighting，在 BCE 上对负样本使用 fold-local risk 权重。
  2. 先跑 5 epoch，对比 base、D4 sampling、PU-weighted BCE、PU-weighted BCE + calibrated threshold。
  3. 如果 AUC/AUPR 至少提升 0.002 且 ACC/MCC 不下降，再跑 30 epoch。

路线 B：针对 ADR 低支持问题

  1. 计算每个 ADR 的正样本支持度，分为 singleton、low、mid、high。
  2. 实现 support-aware loss：低支持 ADR 正样本轻微加权，低支持 ADR 未观测负样本降置信。
  3. 报告总体指标和低支持 ADR 子集指标，形成论文分析亮点。

路线 C：特征稳健性与视图质量

  1. 加入 --normalize_similarity_views，统一 GE/RDKit/DGen/MESH/GDA 分布。
  2. 加入 --view_dropout 或 learned view gate，做视图消融。
  3. 若整体指标提升不大，也可作为解释性/稳健性补充实验。

七、下一步最建议立即实现的改动

1. PU-weighted BCE

把当前风险评分从“采样概率”改为“负样本 loss 权重”。这比删除/少采样更平滑，能保留困难负样本但降低可疑负样本的破坏性。

主攻 AUC/AUPR训练集内完成

2. side-aware risk

把 ADR 相似性纳入伪负风险。DGAPred 当前 ADR 低支持严重，单用 drug 相似性解释不足。

主攻 AUPR利用现有 side matrices

3. support-aware analysis

把低支持 ADR 作为单独评价切片。即使总体提升小，也能形成更有说服力的论文结果分析。

论文友好可解释性强

八、风险控制

  • 不要删除测试集难样本作为正式结果。用户已说明 ADR 测试集约定不用改，但正式论文仍应避免让提升来自测试任务缩小。
  • 所有先验和风险分数应 fold-local 构造，不能使用当前测试 fold 的正样本来指导训练。
  • 低支持实体清洗只能作为数据集变体，不应和原始任务 baseline 混报。
  • 阈值校准可保留，但论文主贡献最好仍包含训练目标或表征层面的改进，否则容易被认为只是后处理。
