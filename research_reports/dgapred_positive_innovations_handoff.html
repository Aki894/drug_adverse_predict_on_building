DGAPred 正向创新点与长线实验交接

生成日期：2026-06-28。服务器约定：从 /data/ccc/ADR 运行，Python 使用 /root/miniconda3/envs/adr/bin/python。

结论摘要

当前最值得交给服务器长线验证的主线不是另起一个全新的大改模型，而是把已经离线筛出稳定正向信号的 directional conditional ADR dependency prior 做成完整 DGAPred integrated prior 实验。

方法核心是只用训练折正样本构造 P(candidate ADR | known ADR)，对同一 drug 已知 ADR profile 给候选 ADR 提供方向性支持，并用 top-k noisy-or 聚合多条 ADR 依赖证据。5% drug-neighbor residual 是轻量增强；semantic MESH/GDA 是 ranking extension；MCC threshold transfer 是 decision-layer 辅助，不建议包装成主创新。

本地正向结果的 baseline 口径

下面的正向结果来自本地 5-fold residual screen，用于筛选方向，不等同于 30 epoch integrated DGAPred 最终结论。所有 residual 先验都只用对应训练折正样本构造，再在 held-out fold 上评估；这是判断“是否值得上服务器长线实验”的低成本口径。

参照项 Epochs AUC AUPR ACC MCC 用途
Fold-local base 5 0.91102 0.90658 0.82887 0.66108 本地 residual screen 的主要 baseline，用于衡量结构先验是否有正向信号。
D4 similarity-negative + graph-prior rank fusion 5 0.91717 0.91298 0.84009 0.68020 上一轮较强短训 fusion 参照；conditional structural residual 后续应至少在 AUPR/ACC/MCC 上超过它。

当前 best non-semantic residual screen 为 AUC 0.92400、AUPR 0.92558、ACC 0.85565、MCC 0.71132；相对 fold-local base 分别为 +0.01298、+0.01900、+0.02678、+0.05024，相对 D4+graph rank fusion 也全指标更高。正式论文指标仍必须以服务器 30 epoch integrated run 为准。

创新点优先级

优先级 创新点 定位 当前证据 论文写法建议
1 Directional conditional ADR dependency prior Core主创新 label-only residual 已有正向信号；top-k noisy-or + drug mean residual 达到 AUC 0.92400、AUPR 0.92558、ACC 0.85565、MCC 0.71132。 可写成“fold-local directional label dependency prior”，强调方向性、训练折内构造、与 DGAPred pair representation 的融合。
2 Small drug-neighbor residual refinement Refinement轻量结构增强 在 conditional label prior 之上用 0.05 mix weight 稳定提升 fixed-threshold 和 MCC-threshold 指标。 作为主方法的一个局部增强模块，不宜单独声称为第二个主创新。
3 Semantic-augmented conditional hybrid prior Extensionranking 扩展 conditional/MESH/GDA = 0.90/0.06/0.04 residual screen 达到 AUC 0.92648、AUPR 0.92642，但 MCC 低于 non-semantic best。 适合写成“semantic support improves ranking metrics”，等待 integrated run 决定是否进入主表。
4 Leave-one-fold MCC threshold transfer Auxiliary决策层辅助 best non-semantic residual 达到 AUC 0.92398、AUPR 0.92557、ACC 0.85582、MCC 0.71166。 只能作为 threshold selection/decision protocol，不应包装成模型结构创新。
5 ASL classification loss / pairwise ranking auxiliary loss Backup备线 代码已实现，但目前优先级低于 structural prior chain。 若 integrated prior 长线失败，再作为 loss-level baseline 或补充消融。

结果判读门槛

  • 若 e30_conditional_topknoisyor12_drugmean_mix005_rank 相对原 DGAPred baseline 在 AUPR/MCC 上稳定正向，可作为主论文方法。
  • 若 label-only 已正向、drug residual 继续提升，可把“方向性 ADR dependency”作为主创新，把 drug residual 写成 refinement。
  • 若 semantic hybrid 只提升 AUC/AUPR、MCC 不升，放入 ranking-metric extension 或 ablation，不强行作为主方法。
  • 若 integrated prior 不如 residual screen，优先检查 prior 注入权重、rank transform、一致的 fold-local 构造和 baseline 协议，再考虑启用 ASL/pairwise 备线。
